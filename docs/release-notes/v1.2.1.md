A small update, and the first one Presenter installs by itself.

## Install

If you have Presenter 1.2.0, you don't need this download: choose **Presenter › Check for Updates…**, or wait for the daily check, and install it from there.

For a new install, download **Presenter-v1.2.1.dmg** below, open it, drag **Presenter** onto the **Applications** shortcut and eject the disk image. The first time, macOS blocks the app because it isn't notarized: double-click it, close the warning, then click **Open Anyway** in **System Settings → Privacy & Security**. Needs macOS 14 Sonoma or later, on Apple Silicon or Intel.

## Fixes

- **Lower Third theme:** a slide's title now sits in the dark band at the bottom with the other words, instead of in the middle of the screen. This applies to new projects; in an existing project, set the theme's **Title** position to the bottom in the theme editor.
