The sixth beta of Presenter, a free macOS app for running slides at church services and live events. You can now **delete images and videos from the media bin**, and a new install starts with a **clean, empty show**: just the starting themes, no sample slides.

## Install

1. Export your project first (File › Export Project…, ⇧⌘S) as a backup.
2. Download **Presenter-v0.1.0-beta.6.zip** below, unzip it, and drag **Presenter** into **Applications**, replacing the older version.
3. The app isn't notarized by Apple, so macOS blocks it the first time. Double-click it, close the warning, then open **System Settings → Privacy & Security** and click **Open Anyway** next to the Presenter message. After that it opens normally.

Needs macOS 14 Sonoma or later. Runs on Apple Silicon and Intel Macs.

Projects keep the same format as beta 5 (version 3), so you can switch between beta 5 and beta 6 freely. Your existing show is untouched: the clean start only applies when there's no saved project yet.

## What's new

### Media
- **Delete media:** right-click an image or video in the media bin and choose **Delete…**.
- **Know what changes:** if slides or themes use the file, Presenter names them first. Those slides lose that background or image.
- **Undo brings it back,** with every slide that used it. Anything on screen stays until you change it.
- **Frees the space:** the file is removed from Presenter's media folder the next time the app opens, unless one of your automatic backups still uses it.

### A clean first launch
- **Only themes to start:** a new install opens an empty show with the Worship, Scripture and Lower Third themes. There are no sample presentations, timers, messages or props, so your library holds only what you add.
- **The same for a damaged project file:** Presenter still moves the file aside without overwriting it, and now opens an empty show instead of the sample one.

## Known limitations

- **Not notarized:** macOS asks you to confirm the app the first time it opens (see Install).
- **Stage display choice:** after the app restarts, the stage display opens in a window; choose its screen again from the Output menu.
- **Export file size:** exported projects include their images and videos, so they can be large.
- **Not in this beta:** scripture, build animations, audio-only tracks, and custom stage display layouts. These are planned for 0.2.

Please report problems on the repository's Issues page, with the steps that led to them and your macOS version. Security problems can be reported privately from the **Security** tab.
