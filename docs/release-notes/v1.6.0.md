Presenter 1.6 adds **Settings › Appearance**, to choose dark or light, a bigger or smaller text size and the colours for LIVE, CUED and each kind of song section, and **Settings › Language**, with Presenter now in **Spanish** as well as English.

Projects keep the same file format as 1.4 and 1.5, so Presenter 1.4 can still open them.

## Install

If you have Presenter 1.2 or later, choose **Presenter › Check for Updates…**, or wait for the daily check, and install it from there.

For a new install, download **Presenter-v1.6.0.dmg** below, open it, drag **Presenter** onto the **Applications** shortcut and eject the disk image. The first time, macOS blocks the app because it isn't notarized: double-click it, close the warning, then click **Open Anyway** in **System Settings → Privacy & Security**. Needs macOS 14 Sonoma or later, on Apple Silicon or Intel.

## Settings

- **Appearance** (Presenter › Settings… › Appearance): **Dark**, **Light** or the same as macOS. Presenter stays dark unless you choose otherwise, so it's quiet in a dark booth. **View › Follow System Appearance** is now the "same as macOS" choice here; a Mac that had it on keeps it.
- **Text size** for Presenter's own windows. Slides, the audience output and the stage display keep their own sizes.
- **Colours** for the LIVE and CUED outlines and badges, and for each kind of song section label on the slide thumbnails (Verse, Chorus, Bridge…). Spanish section names get the same colours.
- Changes show straight away. **Restore Defaults** puts them all back. They're kept on this Mac, not in the project, so each computer can have its own.

## Spanish

- **Presenter en español:** every window, menu and message, including the names new things get and the Undo menu. Settings › Language chooses **English**, **Español** or the system's language.
- macOS sets an app's language when it opens, so the change applies the next time Presenter opens. **Restart Presenter Now** does that straight away, and is greyed out while something is on the audience output.
- Your songs and slides stay as you wrote them.

## Also

- The welcome window shows just the version (Version 1.6.0). **About Presenter** still shows the build number.
- **Presenter for Windows** is in open beta, on the same engine as the Mac app: see the `windows-v` releases. Nothing changes in the Mac app because of it.
