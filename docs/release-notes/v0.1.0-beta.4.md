The fourth beta of Presenter, a free macOS app for running slides at church services and live events. Beta 3's display and video changes have now been checked on a real external display, and the problems that check turned up are fixed: the Output menu is clearer, and Presenter tells you in words when a display is unplugged.

## Install

1. Download **Presenter-v0.1.0-beta.4.zip** below, unzip it, and drag **Presenter** into **Applications**, replacing the older version.
2. The app isn't notarized by Apple, so macOS blocks it the first time. Double-click it, close the warning, then open **System Settings → Privacy & Security** and click **Open Anyway** next to the Presenter message. After that it opens normally.

Needs macOS 14 Sonoma or later. Runs on Apple Silicon and Intel Macs.

**Upgrading from beta 3:** your project opens as it is; the file format hasn't changed. From beta 2 or earlier, read the one-way upgrade note in the beta 3 release first.

## What's new

### Outputs
- **Clearer Output menu:** the first section is now headed **Audience Output**, so it no longer looks like the choice for every output. The stage display is in its own **Stage Display** submenu.
- **No more "Connect another display" by mistake:** if the audience output is using a display, the Stage Display submenu lists it as "GS24F14 – used by the Audience Output" instead of leaving it out. Two outputs still never share a screen.
- **A disconnected display is shown in words:** if you unplug a display during a service, the right-hand panel says, for example, "Audience Output: GS24F14 disconnected. It comes back full screen when you reconnect it." Before, there was only a small warning icon in the toolbar. Hovering that icon now shows the output status too.

### Show
- **Clear Background explains itself:** clearing the background only lasts until a slide with its own background goes live, as in ProPresenter. Presenter now says so under the Audience preview after a clear, and points you to the slide's **Background** button to remove it for good.

### Look
- Spacing in the operator and editor windows now follows one scale. A few gaps move by a point or two.

## Tested on a second display

Beta 3 changed how Presenter places outputs on screens and how video mute is tracked. This beta was checked on an external 1920×1080 display:
- the stage display and the audience output each go full screen on their own display;
- unplugging and replugging a display: the output hides, then comes back full screen on the same display by itself;
- video mute from the transport lasts across slide changes, forwards and back;
- the "Exporting…" progress sheet shows for a large project with video, and the window keeps responding.

## Known limitations

- **Not notarized:** macOS asks you to confirm the app the first time it opens (see Install).
- **Stage display choice:** after the app restarts, the stage display opens in a window; choose its screen again from the Output menu.
- **Export file size:** exported projects include their images and videos, so they can be large.
- **Not in this beta:** build animations, audio-only tracks, and custom stage display layouts.

Please report problems on the repository's Issues page, with the steps that led to them. Security problems can be reported privately from the **Security** tab.
