A small update: a clearer message when Presenter can't check for updates.

Projects keep the same file format as 1.4 to 1.6, so Presenter 1.4 can still open them.

## Install

If you have Presenter 1.2 or later, choose **Presenter › Check for Updates…**, or wait for the daily check, and install it from there.

For a new install, download **Presenter-v1.6.2.dmg** below, open it, drag **Presenter** onto the **Applications** shortcut and eject the disk image. The first time, macOS blocks the app because it isn't notarized: double-click it, close the warning, then click **Open Anyway** in **System Settings → Privacy & Security**. Needs macOS 14 Sonoma or later, on Apple Silicon or Intel.

## Fixes

- **Checking for updates without a connection:** when Presenter can't reach the update server (no internet, or a connection that times out), it now says so — "Presenter couldn't reach the update server" — and suggests checking the connection and trying again. Before, it showed only "Update Error! An error occurred in retrieving update information", which looked like something was wrong with Presenter. In Spanish too.
