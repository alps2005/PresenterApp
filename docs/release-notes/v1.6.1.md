A small update with two fixes for Presenter in Spanish.

Projects keep the same file format as 1.4 to 1.6, so Presenter 1.4 can still open them.

## Install

If you have Presenter 1.2 or later, choose **Presenter › Check for Updates…**, or wait for the daily check, and install it from there.

For a new install, download **Presenter-v1.6.1.dmg** below, open it, drag **Presenter** onto the **Applications** shortcut and eject the disk image. The first time, macOS blocks the app because it isn't notarized: double-click it, close the warning, then click **Open Anyway** in **System Settings → Privacy & Security**. Needs macOS 14 Sonoma or later, on Apple Silicon or Intel.

## Fixes

- **Welcome window:** the **New Show** button is now the same size as **Open Project…** and **Import Songs…**, and its name fits in Spanish ("Nuevo programa" was cut short). Clicking it opens its menu: **New Empty Show…** or **Duplicate** the selected show.
- **Copies named in Spanish:** duplicating a show, macro, theme or stage layout in Spanish now names the copy "Domingo (copia)" instead of "Domingo Copy".
