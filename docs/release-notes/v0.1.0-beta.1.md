The first beta of Presenter, a free macOS app for running slides at church services and live events. The operator controls everything from one window while the audience sees only the slides.

## Install

1. Download **Presenter-v0.1.0-beta.1.zip** below, unzip it, and drag **Presenter** into **Applications**.
2. The app isn't notarized by Apple, so macOS blocks it the first time. Double-click it, close the warning, then open **System Settings → Privacy & Security** and click **Open Anyway** next to the Presenter message. After that it opens normally.

Needs macOS 14 Sonoma or later. Runs on Apple Silicon and Intel Macs.

## What's in this beta

- **Running a service:** a playlist of presentations shown one after another in a single scrolling workspace. Click a slide to cue it, double-click or press Return to take it live, and use → / Space / ← to move through the whole service. Clear, Blackout and Restore are always one keystroke away.
- **Audience output:** in a window for rehearsing, or full screen on a second display. If the display disconnects, the output hides and comes back when it reconnects.
- **Songs:** New Song… (⌥⌘N) turns pasted lyrics into one slide per stanza, with Verse/Chorus/Bridge labels (Verso, Coro, Puente too).
- **Slide editor:** a Keynote-style editor for text boxes, shapes and images, with alignment guides that snap to the slide's centre and edges, copy/paste, duplicate, and a dissolve transition.
- **Quick Edit (⌥⌘E):** fix a slide's text, style or background during a service.
- **Undo and redo (⌘Z / ⇧⌘Z):** cover every edit. Undo never changes what the audience sees.
- **Saving:** autosave, plus Export/Open to move a project, with its images, to another Mac.

## Known limitations

- **Second display:** full-screen output on a projector hasn't been tested on real hardware yet. Rehearse once on the church computer before a service.
- **Not notarized:** macOS asks you to confirm the app the first time it opens (see Install).
- **Not in this beta:** build animations, audio and video, and a stage display.
- **Export file size:** an exported project file can be large, because its images are stored inside it.

Please report problems on the repository's Issues page, with the steps that led to them.
